# MaxScore Implementation Plan (#271)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make OR queries and pairs of very frequent words fast by skipping candidates and full scorings that provably can't reach the top K, with results identical to an exhaustive search.

**Architecture:** Two small bound primitives (a term's ceiling in `Scorer`, a posting's count-only bound in `Cursor`), then a rewrite of `walk` in `src/search.rs`. In the rewrite, the lead group's lowest-ceiling terms become "passive" (looked up only to finish a score), and each candidate passes a ladder of cheaper-to-dearer upper bounds before it is fully scored. No format change.

**Tech Stack:** Rust (edition as in `Cargo.toml`), `cargo test`, `cargo fmt`.

**Spec:** `docs/superpowers/specs/2026-10-15-maxscore-design.md`

## Global Constraints

- Segments stay v2; no change to the segment format, `VERSION`, the API or the output strings.
- Results must equal the exhaustive search for every query and K (#248's guard test stays and grows).
- Every skip is `bound * (1.0 + SLACK) < threshold` with `SLACK = 1e-9` (strict, so ties are scored).
- Buffers, totals, the heap and its order, the dead set and snapshots are unchanged.
- Release: v0.4.4.
- CI runs `cargo fmt --all -- --check && cargo test`; both must pass before every commit.
- Comments match the surrounding style: short, lower-case `//` lines, `///`/`/** */` doc comments on public items, issue numbers in parentheses like `(#271)`.

## Review Focus

1. **A posting whose page has no stored length** (the writer counts it as length 0): the count-only bound must still be at or above its weight, or search would drop a page the exhaustive search ranks. Pinned in Task 1 (`a_posting_whose_page_has_no_length_is_under_its_count_bound`).
2. **Ties at θ where a later-walked page has a lower id** (the buffer is scored before the segments, and holds the newest, highest ids): a skip on `bound == θ` would keep the wrong pages. Pinned in Task 2 (`pages_tied_with_the_kth_score_are_still_ranked_by_id`).
3. **A term in two groups** (`(a OR b) a`): its ceiling counts in both groups' bounds but its weight once in the score. The existing `a_term_in_two_groups_is_scored_once` runs against the new walk in Task 2, and Task 2 adds a fixed query of that shape to the randomized test.
4. **A segment that lacks one of an OR group's terms**: the group's ceiling covers only the terms present, so the walk can end at once. Pinned in Task 2 (`a_segment_whose_terms_cant_reach_the_kth_score_is_left_unread`).
5. **Very large counts or length 0** in the ceiling, where `count / (count + norm)` can round to 1.0: the ceiling must still not be below a weight. Pinned in Task 1 (`no_weight_exceeds_its_terms_ceiling`, which uses `<=`).

```rust
     * The most `weight` comes to for a posting in the current block with `count`, given a weight
     * that grows with count and falls with page length (#271): its weight at the length of the
     * first impact whose count reaches `count`. Impacts ascend in both, so that's the shortest
     * page any impact covering the posting allows. Infinite if no impact reaches it (a garbled

            match b.impacts.pairs().iter().find(|&&(c, _)| c >= count) {
                Some(&(_, length)) => weight(count, length),
                None => f64::INFINITY,
            }
        })
    }
```

```rust
fn below(bound: f64, threshold: f64) -> bool {
    bound * (1.0 + SLACK) < threshold

/**
 * How many of the lead group's terms, lowest ceiling first, can't make the top K even with every
 * other group at its ceiling (`rest`) (#271): the longest prefix of `ceilings` (ascending) whose
 * sum plus `rest` is below `threshold`. Candidates come only from the terms after it.
 */
fn passive_terms(ceilings: &[f64], rest: f64, threshold: f64) -> usize {
    let mut sum = rest;
    for (n, &ceiling) in ceilings.iter().enumerate() {
        sum += ceiling;
        if !below(sum, threshold) {
            return n;
        }
    }
    ceilings.len()
}
```

```rust
// an OR group's cursors in one segment. In the lead group, the first `passive` (the lowest
// ceilings) can't make the top K by themselves: they're only looked up to finish a score (#271)
struct Group<'a> {
    cursors: Vec<TermCursor<'a>>,
    passive: usize,
}

impl<'a> Group<'a> {
    fn df(&self) -> u64 {
        self.cursors.iter().map(|c| c.cursor.df()).sum()
    }

    // the cursors that supply candidates
    fn active(&self) -> &[TermCursor<'a>] {
        &self.cursors[self.passive..]
    }

    fn active_mut(&mut self) -> &mut [TermCursor<'a>] {
        &mut self.cursors[self.passive..]
    }

    fn done(&self) -> bool {
        self.active().iter().all(|c| c.cursor.done())
    }

    // every active cursor to the block that could hold `target`, reading headers only
    fn seek_block(&mut self, target: u64) -> io::Result<()> {
        for c in self.active_mut() {
            c.cursor.seek_block(target)?;
        }
        Ok(())
    }

    // the smallest last id among the active cursors' blocks: up to it, their bounds hold
    fn block_end(&self) -> Option<u64> {
        self.active()
            .iter()
            .filter_map(|c| c.cursor.block_last())
            .min()
    }

    // the most a page in the current blocks can score from this group's active terms
    fn bound(&self, scorer: &Scorer) -> f64 {
        self.active()
            .iter()
            .map(|c| {
                c.cursor
                    .block_bound(|count, length| scorer.weight(c.term, count, length))
            })
            .sum()
    }

    // the most this group's terms can score on any page (#271)
    fn ceiling(&self, scorer: &Scorer) -> f64 {
        self.cursors.iter().map(|c| scorer.ceiling(c.term)).sum()
    }

    // every active cursor to its first page at or after `target`; the first of those, none if done
    fn seek(&mut self, target: u64) -> io::Result<Option<u64>> {
        let mut first: Option<u64> = None;
        for c in self.active_mut() {
            if let Some((id, _)) = c.cursor.seek(target)? {
                first = Some(first.map_or(id, |f| f.min(id)));
            }
        }
        Ok(first)
    }

    // the passive cursors to `id`, to finish its score
    fn seek_passive(&mut self, id: u64) -> io::Result<()> {
        for c in self.cursors[..self.passive].iter_mut() {
            c.cursor.seek(id)?;
        }
        Ok(())
    }

    // how many of the active cursors sit on `id`: its postings in this group
    fn on(&mut self, id: u64) -> io::Result<u64> {
        let mut n = 0;
        for c in self.active_mut() {
            if c.cursor.current()?.is_some_and(|(at, _)| at == id) {
                n += 1;
            }
        }
        Ok(n)
    }

    // the active cursors on `id`: the most their counts allow, before its length is known (#271)
    fn count_bound(&mut self, scorer: &Scorer, id: u64) -> io::Result<f64> {
        let mut bound = 0.0;
        for c in self.active_mut() {
            if let Some((at, count)) = c.cursor.current()? {
                if at == id {
                    let term = c.term;
                    bound += c
                        .cursor
                        .count_bound(count, |n, l| scorer.weight(term, n, l));
                }
            }
        }
        Ok(bound)
    }

    // the active cursors on `id`: their weights on a page of `length`
    fn weight(&mut self, scorer: &Scorer, id: u64, length: u32) -> io::Result<f64> {
        let mut weight = 0.0;
        for c in self.active_mut() {
            if let Some((at, count)) = c.cursor.current()? {
                if at == id {
                    weight += scorer.weight(c.term, count, length);
                }
            }
        }
        Ok(weight)
    }
}
```

Replace the whole `walk` function (its comment line and body) with:

```rust
/**
 * Offers one segment's matches to `top` (#248, #271). Regions of blocks whose bound can't make
 * it are skipped by their headers. In the lead group, terms whose ceilings can't make it even
 * with every other group at its ceiling go passive: candidates come only from the rest. Each
 * candidate is dropped at the first upper bound below the K-th score: its counts alone, then
 * its lead weights, then each other group's weight in turn; only what's left is fully scored.
 */
fn walk(
    segment: &Segment,
    query: &Query,
    scorer: &Scorer,
    view: &View,
    top: &mut TopK,
) -> io::Result<()> {
    let Some(mut groups) = open_groups(segment, query)? else {
        return Ok(());
    };
    let lead = lead(&groups);
    // the lead's terms by ceiling, lowest first, so the passive ones are a prefix
    groups[lead]
        .cursors
        .sort_by(|a, b| scorer.ceiling(a.term).total_cmp(&scorer.ceiling(b.term)));
    let ceilings: Vec<f64> = groups[lead]
        .cursors
        .iter()
        .map(|c| scorer.ceiling(c.term))
        .collect();
    // the other groups, and for each, the sum of the ceilings of those after it; summed rather
    // than subtracted, so rounding can't take a bound below a score
    let others: Vec<usize> = (0..groups.len()).filter(|&g| g != lead).collect();
    let mut beyond = vec![0.0; others.len()];
    for i in (0..others.len().saturating_sub(1)).rev() {
        beyond[i] = beyond[i + 1] + groups[others[i + 1]].ceiling(scorer);
    }
    let rest = others
        .first()
        .map_or(0.0, |&g| groups[g].ceiling(scorer) + beyond[0]);
    let mut target = 0u64;
    loop {
        // θ only rises, so terms only go passive
        let passive = passive_terms(&ceilings, rest, top.threshold()).max(groups[lead].passive);
        if passive == ceilings.len() {
            // no page left here can make the top K
            return Ok(());
        }
        groups[lead].passive = passive;
        let passive_ceiling: f64 = ceilings[..passive].iter().sum();
        for group in groups.iter_mut() {
            group.seek_block(target)?;
            if group.done() {
                return Ok(());
            }
        }
        // ids from target to end are each in their cursors' current blocks, if anywhere
        let end = groups.iter().filter_map(Group::block_end).min().unwrap();
        let bound = passive_ceiling + groups.iter().map(|g| g.bound(scorer)).sum::<f64>();
        if below(bound, top.threshold()) {
            // a garbled last id of u64::MAX would wrap back to 0 and loop
            let Some(after) = end.checked_add(1) else {
                return Ok(());
            };
            target = after;
            continue;
        }
        let Some(candidate) = groups[lead].seek(target)? else {
            return Ok(());
        };
        if candidate > end {
            target = candidate;
            continue;
        }
        #[cfg(test)]
        CANDIDATES.with(|c| c.set(c.get() + 1));
        let mut next = candidate.checked_add(1);
        'consider: {
            if view.is_dead(candidate) {
                break 'consider;
            }
            let threshold = top.threshold();
            // its counts alone, at the shortest length their blocks allow
            let counts = groups[lead].count_bound(scorer, candidate)?;
            if below(counts + passive_ceiling + rest, threshold) {
                break 'consider;
            }
            let length = segment.length(candidate).unwrap_or(0);
            let mut exact = groups[lead].weight(scorer, candidate, length)?;
            if below(exact + passive_ceiling + rest, threshold) {
                break 'consider;
            }
            for (i, &g) in others.iter().enumerate() {
                match groups[g].seek(candidate)? {
                    None => return Ok(()),
                    Some(id) if id > candidate => {
                        next = Some(id);
                        break 'consider;
                    }
                    Some(_) => {}
                }
                exact += groups[g].weight(scorer, candidate, length)?;
                if below(exact + passive_ceiling + beyond[i], threshold) {
                    break 'consider;
                }
            }
            groups[lead].seek_passive(candidate)?;
            #[cfg(test)]
            SCORED.with(|s| s.set(s.get() + 1));
            let score = score(&mut groups, query, scorer, candidate, length)?;
            top.offer(score, candidate);
        }
        match next {
            Some(id) => target = id,
            None => return Ok(()),
        }
    }
}
```

Notes for the implementer:
- `score` (unchanged) needs every cursor at or past `candidate`: the active lead cursors are (from `seek`), the other groups are (seeked in the loop), and the passive ones are after `seek_passive`.
- `count()` (totals) builds its groups with `open_groups`, so `passive` is 0 there and `on`/`seek` behave as before.
- If clippy-style borrow errors come up in `count_bound` because of the closure, the `let term = c.term;` copy is what avoids them; keep it.

```rust
 * (MaxScore, #271). The buffer is scored in full. Totals are the dictionary df for one word, an
```
