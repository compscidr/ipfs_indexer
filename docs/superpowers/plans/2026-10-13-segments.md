# Segmented Inverted Index with Takedown Erasure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move postings out of SQLite into immutable segment files (#247), with takedowns hiding a page at once and erasing its terms from every file under `DATA_DIR` promptly (#249).

**Architecture:** `src/segment.rs` is one segment file: a writer and a reader, with no SQLite. `src/segments.rs` is the set of segments: manifest, in-memory write buffer, dead-id set, and `maintain()` (flush, erase, merge, retire). `src/store.rs` keeps `pages`, `queue`, `mirrors` and a new `dead_pages` table in SQLite, and calls into `Segments`. `IndexQueue::search` works on page ids. A background thread in `main.rs` runs `maintain()`.

**Tech Stack:** Rust 2021 (rustc 1.92), rusqlite 0.40 (bundled), std only. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-segments-design.md`

## Global Constraints

- No new crates in `Cargo.toml`.
- Every file that ever held page text and is being discarded is overwritten with zeros, fsynced, then unlinked (`segments::erase_file`). Never just `remove_file` a `.seg`.
- `PRAGMA secure_delete = ON` and `journal_mode = MEMORY` stay. The migration sets `temp_store = MEMORY` before any `ORDER BY` or `VACUUM`, so no temp file holds plaintext.
- Page ids are never reused (`AUTOINCREMENT`). A re-crawl gets a new id.
- Flush thresholds: 1,000,000 postings or 60 s. Merge fan-out: 10 segments per tier, where tier = `floor(log10(bytes / 1 MiB))`. Rewrite alone at ≥ 20 % dead docs. Block size 128 postings. A sparse index entry every 64 dictionary terms.
- Segment files: `$DATA_DIR/segments/<16 hex digits>.seg`. The manifest is `$DATA_DIR/segments/MANIFEST`, written via `MANIFEST.tmp` + fsync + rename + directory fsync.
- Comments match the codebase: short, lower-case line comments that say *why*, `/** */` doc blocks on public items that need more than a line, and issue numbers in parentheses (`(#247)`).
- `cargo fmt --check` and `cargo test` pass at the end of every task.

## Review Focus

1. **Terms with non-ASCII bytes** (`"café"`, `"日本"`) must sort identically in the writer's assert, `BTreeMap<String, _>`, and SQLite's `ORDER BY term`. All three compare bytewise; Task 1 pins it with a test.
2. **A page with no terms** (an empty body) must flush into a valid segment and must not break `contains`, merges or recovery. Task 2.
3. **A failed segment write** (disk full, I/O error) must leave no partial `.seg` with page text, and the buffer must not be lost. Task 2 tests the erase-on-error path.
4. **Restart after a clean stop vs. a crash.** After a clean drop, everything is still searchable. After a crash, unflushed pages are re-queued, not lost. Task 4.
5. **A takedown matching only an old version's redirected cid.** The old version's segment must still be rewritten. Task 5.

```rust
/*!
 * One immutable segment file of the inverted index (#247). Version 1 layout, integers as LEB128
 * varints unless marked:
 *
 *   header    "ipxseg", version u8
 *   docs      (id delta, length) per page, ascending by id
 *   postings  per term, blocks of up to BLOCK postings: n, last id, body bytes, max count (for
 *             #248's block-max pruning, unused so far); then the id deltas, then the counts
 *   dict      per term, ascending bytewise: shared prefix, suffix length, suffix, df, offset of
 *             its first block; prefixes restart every SPARSE terms
 *   sparse    every SPARSE-th term: length, term, its dict entry's offset within dict
 *   footer    docs, postings, dict and sparse offsets, page count, min id, max id (u64 LE each),
 *             FNV-1a 64 of everything before it (u64 LE), "ipxend"
 */
use std::fs::{File, OpenOptions};
use std::io::{self, BufReader, BufWriter, Read, Seek, SeekFrom, Write};
use std::os::unix::fs::FileExt;
use std::path::{Path, PathBuf};

/// (page id, how often the term appears on it)
pub type Posting = (u64, u32);

const BLOCK: usize = 128;
const SPARSE: u64 = 64;
const MAGIC: &[u8] = b"ipxseg";
const VERSION: u8 = 1;
const END: &[u8] = b"ipxend";
const FOOTER: u64 = 7 * 8 + 8 + 6;
const FNV_OFFSET: u64 = 0xcbf29ce484222325;

#[derive(Clone, Copy, Debug, PartialEq)]
pub struct SegmentInfo {
    pub docs: u64,
    pub min_id: u64,
    pub max_id: u64,
    pub bytes: u64,
}

fn corrupt() -> io::Error {
    io::Error::new(io::ErrorKind::InvalidData, "corrupt segment file")
}

fn fnv1a(hash: u64, bytes: &[u8]) -> u64 {
    bytes
        .iter()
        .fold(hash, |h, &b| (h ^ b as u64).wrapping_mul(0x100000001b3))
}

fn put_varint(out: &mut Vec<u8>, mut value: u64) {
    loop {
        let byte = (value & 0x7f) as u8;
        value >>= 7;
        if value == 0 {
            out.push(byte);
            return;
        }
        out.push(byte | 0x80);
    }
}

fn get_varint(buf: &[u8], pos: &mut usize) -> io::Result<u64> {
    let mut value = 0u64;
    let mut shift = 0;
    loop {
        let byte = *buf.get(*pos).ok_or_else(corrupt)?;
        *pos += 1;
        if shift > 63 {
            return Err(corrupt());
        }
        value |= ((byte & 0x7f) as u64) << shift;
        if byte & 0x80 == 0 {
            return Ok(value);
        }
        shift += 7;
    }
}

fn read_varint(reader: &mut impl Read) -> io::Result<u64> {
    let mut value = 0u64;
    let mut shift = 0;
    loop {
        let mut byte = [0u8];
        reader.read_exact(&mut byte)?;
        if shift > 63 {
            return Err(corrupt());
        }
        value |= ((byte[0] & 0x7f) as u64) << shift;
        if byte[0] & 0x80 == 0 {
            return Ok(value);
        }
        shift += 7;
    }
}

fn read_at(file: &File, offset: u64, len: u64) -> io::Result<Vec<u8>> {
    let mut buf = vec![0; len as usize];
    file.read_exact_at(&mut buf, offset)?;
    Ok(buf)
}

pub struct SegmentWriter {
    out: BufWriter<File>,
    pos: u64,
    hash: u64,
    docs: u64,
    min_id: u64,
    max_id: u64,
    postings_off: Option<u64>,
    dict: Vec<u8>,
    sparse: Vec<u8>,
    terms: u64,
    last_term: Vec<u8>,
}

impl SegmentWriter {
    /// Starts a new segment file; fails if `path` exists
    pub fn create(path: &Path) -> io::Result<SegmentWriter> {
        let file = OpenOptions::new().write(true).create_new(true).open(path)?;
        let mut writer = SegmentWriter {
            out: BufWriter::new(file),
            pos: 0,
            hash: FNV_OFFSET,
            docs: 0,
            min_id: 0,
            max_id: 0,
            postings_off: None,
            dict: Vec::new(),
            sparse: Vec::new(),
            terms: 0,
            last_term: Vec::new(),
        };
        writer.write(MAGIC)?;
        writer.write(&[VERSION])?;
        Ok(writer)
    }

    fn write(&mut self, bytes: &[u8]) -> io::Result<()> {
        self.out.write_all(bytes)?;
        self.hash = fnv1a(self.hash, bytes);
        self.pos += bytes.len() as u64;
        Ok(())
    }

    /// A page and its length; ids ascending, all before the first term
    pub fn add_doc(&mut self, id: u64, length: u32) -> io::Result<()> {
        assert!(self.postings_off.is_none(), "pages come before terms");
        assert!(self.docs == 0 || id > self.max_id, "page ids must ascend");
        let mut buf = Vec::new();
        put_varint(&mut buf, id - if self.docs == 0 { 0 } else { self.max_id });
        put_varint(&mut buf, length as u64);
        self.write(&buf)?;
        if self.docs == 0 {
            self.min_id = id;
        }
        self.max_id = id;
        self.docs += 1;
        Ok(())
    }

    /// A term and the pages it's on; terms ascending bytewise, postings ascending by id
    pub fn add_term(&mut self, term: &[u8], postings: &[Posting]) -> io::Result<()> {
        assert!(!postings.is_empty(), "a term is on at least one page");
        assert!(
            self.terms == 0 || term > self.last_term.as_slice(),
            "terms must ascend"
        );
        if self.postings_off.is_none() {
            self.postings_off = Some(self.pos);
        }
        let offset = self.pos;
        let mut prev = 0u64;
        for block in postings.chunks(BLOCK) {
            let mut body = Vec::new();
            for &(id, _) in block {
                put_varint(&mut body, id - prev);
                prev = id;
            }
            for &(_, count) in block {
                put_varint(&mut body, count as u64);
            }
            let mut head = Vec::new();
            put_varint(&mut head, block.len() as u64);
            put_varint(&mut head, prev);
            put_varint(&mut head, body.len() as u64);
            put_varint(&mut head, block.iter().map(|p| p.1).max().unwrap() as u64);
            self.write(&head)?;
            self.write(&body)?;
        }
        // every SPARSE-th entry is written whole and indexed, so a lookup can start there
        let shared = if self.terms % SPARSE == 0 {
            put_varint(&mut self.sparse, term.len() as u64);
            self.sparse.extend_from_slice(term);
            put_varint(&mut self.sparse, self.dict.len() as u64);
            0
        } else {
            self.last_term
                .iter()
                .zip(term)
                .take_while(|(a, b)| a == b)
                .count()
        };
        put_varint(&mut self.dict, shared as u64);
        put_varint(&mut self.dict, (term.len() - shared) as u64);
        self.dict.extend_from_slice(&term[shared..]);
        put_varint(&mut self.dict, postings.len() as u64);
        put_varint(&mut self.dict, offset);
        self.last_term = term.to_vec();
        self.terms += 1;
        Ok(())
    }

    /// Writes the dictionary and footer and fsyncs the file
    pub fn finish(mut self) -> io::Result<SegmentInfo> {
        let docs_off = (MAGIC.len() + 1) as u64;
        let postings_off = self.postings_off.unwrap_or(self.pos);
        let dict_off = self.pos;
        let dict = std::mem::take(&mut self.dict);
        self.write(&dict)?;
        let sparse_off = self.pos;
        let sparse = std::mem::take(&mut self.sparse);
        self.write(&sparse)?;
        let mut footer = Vec::new();
        for value in [
            docs_off,
            postings_off,
            dict_off,
            sparse_off,
            self.docs,
            self.min_id,
            self.max_id,
        ] {
            footer.extend_from_slice(&value.to_le_bytes());
        }
        self.write(&footer)?;
        let hash = self.hash;
        self.write(&hash.to_le_bytes())?;
        self.write(END)?;
        let file = self.out.into_inner().map_err(|e| e.into_error())?;
        file.sync_all()?;
        Ok(SegmentInfo {
            docs: self.docs,
            min_id: self.min_id,
            max_id: self.max_id,
            bytes: self.pos,
        })
    }
}

/// An open segment file. Page ids and lengths and the sparse term index are held in memory;
/// dictionary entries and postings are read on demand.
pub struct Segment {
    file: File,
    path: PathBuf,
    info: SegmentInfo,
    dict_off: u64,
    sparse_off: u64,
    // every SPARSE-th term and the absolute offset of its dict entry
    sparse: Vec<(Vec<u8>, u64)>,
    ids: Vec<u64>,
    lengths: Vec<u32>,
}

impl Segment {
    /// Opens and verifies (checksum, then structure) a segment file
    pub fn open(path: &Path) -> io::Result<Segment> {
        let file = File::open(path)?;
        let bytes = file.metadata()?.len();
        if bytes < MAGIC.len() as u64 + 1 + FOOTER {
            return Err(corrupt());
        }
        let footer = read_at(&file, bytes - FOOTER, FOOTER)?;
        if &footer[footer.len() - END.len()..] != END {
            return Err(corrupt());
        }
        let field = |i: usize| u64::from_le_bytes(footer[i * 8..i * 8 + 8].try_into().unwrap());
        let checked = bytes - 8 - END.len() as u64;
        let mut hash = FNV_OFFSET;
        let mut chunk = vec![0u8; 1 << 20];
        let mut offset = 0;
        while offset < checked {
            let n = (checked - offset).min(chunk.len() as u64) as usize;
            file.read_exact_at(&mut chunk[..n], offset)?;
            hash = fnv1a(hash, &chunk[..n]);
            offset += n as u64;
        }
        if hash != field(7) {
            return Err(corrupt());
        }
        let header = read_at(&file, 0, MAGIC.len() as u64 + 1)?;
        if &header[..MAGIC.len()] != MAGIC {
            return Err(corrupt());
        }
        if header[MAGIC.len()] != VERSION {
            return Err(io::Error::new(
                io::ErrorKind::Unsupported,
                "unsupported segment version",
            ));
        }
        let (docs_off, postings_off, dict_off, sparse_off) = (field(0), field(1), field(2), field(3));
        if !(docs_off <= postings_off
            && postings_off <= dict_off
            && dict_off <= sparse_off
            && sparse_off <= bytes - FOOTER)
        {
            return Err(corrupt());
        }
        let info = SegmentInfo {
            docs: field(4),
            min_id: field(5),
            max_id: field(6),
            bytes,
        };

        let raw = read_at(&file, docs_off, postings_off - docs_off)?;
        let (mut ids, mut lengths) = (Vec::new(), Vec::new());
        let (mut pos, mut id) = (0, 0u64);
        while pos < raw.len() {
            id += get_varint(&raw, &mut pos)?;
            ids.push(id);
            lengths.push(get_varint(&raw, &mut pos)? as u32);
        }
        if ids.len() as u64 != info.docs {
            return Err(corrupt());
        }

        let raw = read_at(&file, sparse_off, bytes - FOOTER - sparse_off)?;
        let mut sparse = Vec::new();
        let mut pos = 0;
        while pos < raw.len() {
            let len = get_varint(&raw, &mut pos)? as usize;
            let term = raw.get(pos..pos + len).ok_or_else(corrupt)?.to_vec();
            pos += len;
            sparse.push((term, dict_off + get_varint(&raw, &mut pos)?));
        }
        Ok(Segment {
            file,
            path: path.to_path_buf(),
            info,
            dict_off,
            sparse_off,
            sparse,
            ids,
            lengths,
        })
    }

    pub fn info(&self) -> SegmentInfo {
        self.info
    }

    pub fn path(&self) -> &Path {
        &self.path
    }

    pub fn contains(&self, id: u64) -> bool {
        self.ids.binary_search(&id).is_ok()
    }

    /// The page's length in terms, if it's in this segment
    pub fn length(&self, id: u64) -> Option<u32> {
        self.ids.binary_search(&id).ok().map(|i| self.lengths[i])
    }

    /// (page id, length), ascending by id
    pub fn docs(&self) -> impl Iterator<Item = (u64, u32)> + '_ {
        self.ids.iter().copied().zip(self.lengths.iter().copied())
    }

    /// The postings for a term, or none if it isn't in this segment
    pub fn postings(&self, term: &[u8]) -> io::Result<Vec<Posting>> {
        match self.find(term)? {
            Some((df, offset)) => self.postings_at(df, offset),
            None => Ok(Vec::new()),
        }
    }

    // (df, postings offset) of a term: binary search the sparse index, then scan one chunk
    fn find(&self, term: &[u8]) -> io::Result<Option<(u64, u64)>> {
        let i = match self
            .sparse
            .binary_search_by(|(t, _)| t.as_slice().cmp(term))
        {
            Ok(i) => i,
            Err(0) => return Ok(None),
            Err(i) => i - 1,
        };
        let start = self.sparse[i].1;
        let end = self.sparse.get(i + 1).map_or(self.sparse_off, |s| s.1);
        let chunk = read_at(&self.file, start, end - start)?;
        let (mut pos, mut current) = (0, Vec::new());
        while pos < chunk.len() {
            let shared = get_varint(&chunk, &mut pos)? as usize;
            let len = get_varint(&chunk, &mut pos)? as usize;
            if shared > current.len() {
                return Err(corrupt());
            }
            current.truncate(shared);
            current.extend_from_slice(chunk.get(pos..pos + len).ok_or_else(corrupt)?);
            pos += len;
            let df = get_varint(&chunk, &mut pos)?;
            let offset = get_varint(&chunk, &mut pos)?;
            match current.as_slice().cmp(term) {
                std::cmp::Ordering::Equal => return Ok(Some((df, offset))),
                std::cmp::Ordering::Greater => return Ok(None),
                std::cmp::Ordering::Less => {}
            }
        }
        Ok(None)
    }

    /// Reads `df` postings starting at a dictionary entry's offset
    pub fn postings_at(&self, df: u64, mut offset: u64) -> io::Result<Vec<Posting>> {
        let mut out = Vec::with_capacity(df as usize);
        let mut prev = 0u64;
        while (out.len() as u64) < df {
            // a block header is four varints, at most 40 bytes
            let head = read_at(&self.file, offset, 40.min(self.dict_off.saturating_sub(offset)))?;
            let mut pos = 0;
            let n = get_varint(&head, &mut pos)? as usize;
            let _last = get_varint(&head, &mut pos)?;
            let body_len = get_varint(&head, &mut pos)?;
            let _max_count = get_varint(&head, &mut pos)?;
            if n == 0 || n > BLOCK {
                return Err(corrupt());
            }
            let body = read_at(&self.file, offset + pos as u64, body_len)?;
            let mut bpos = 0;
            let mut ids = Vec::with_capacity(n);
            for _ in 0..n {
                prev += get_varint(&body, &mut bpos)?;
                ids.push(prev);
            }
            for id in ids {
                out.push((id, get_varint(&body, &mut bpos)? as u32));
            }
            offset += pos as u64 + body_len;
        }
        Ok(out)
    }

    /// Every term in order, as (term, df, postings offset), streamed from the file
    pub fn terms(&self) -> io::Result<Terms> {
        // its own handle: a cloned one would share (and move) this one's file offset
        let mut file = File::open(&self.path)?;
        file.seek(SeekFrom::Start(self.dict_off))?;
        Ok(Terms {
            reader: BufReader::new(file).take(self.sparse_off - self.dict_off),
            term: Vec::new(),
        })
    }
}

pub struct Terms {
    reader: io::Take<BufReader<File>>,
    term: Vec<u8>,
}

impl Terms {
    fn entry(&mut self) -> io::Result<(Vec<u8>, u64, u64)> {
        let shared = read_varint(&mut self.reader)? as usize;
        let len = read_varint(&mut self.reader)? as usize;
        if shared > self.term.len() {
            return Err(corrupt());
        }
        self.term.truncate(shared);
        let mut suffix = vec![0; len];
        self.reader.read_exact(&mut suffix)?;
        self.term.extend_from_slice(&suffix);
        let df = read_varint(&mut self.reader)?;
        let offset = read_varint(&mut self.reader)?;
        Ok((self.term.clone(), df, offset))
    }
}

impl Iterator for Terms {
    type Item = io::Result<(Vec<u8>, u64, u64)>;

    fn next(&mut self) -> Option<Self::Item> {
        if self.reader.limit() == 0 {
            return None;
        }
        let entry = self.entry();
        if entry.is_err() {
            // stop after an error rather than reading garbage
            self.reader.set_limit(0);
        }
        Some(entry)
    }
}
```

```rust
/*!
 * The segment set (#247): the segment files named by MANIFEST, a write buffer of recent
 * postings, and the dead page ids that search filters out (#249). maintain(), run on a background
 * thread, flushes the buffer to a new segment, rewrites segments holding pages to erase, merges
 * segments, and zeroes and removes retired files once no search still reads them.
 */
use crate::segment::{Posting, Segment, SegmentWriter};
use std::collections::{BTreeMap, HashMap, HashSet};
use std::fs::{self, File, OpenOptions};
use std::io::{self, Write};
use std::path::{Path, PathBuf};
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::{Arc, Condvar, Mutex, RwLock};
use std::time::{Duration, Instant};

const FLUSH_POSTINGS: usize = 1_000_000;
const FLUSH_AGE: Duration = Duration::from_secs(60);

#[derive(Default)]
struct Buffer {
    postings: BTreeMap<String, Vec<Posting>>,
    lengths: BTreeMap<u64, u32>,
    // postings held
    count: usize,
    // the highest id ever added, even if since removed
    max_id: u64,
    // when the first page arrived
    since: Option<Instant>,
}

// what a search reads besides the live buffer, swapped as one so a flush is never half-seen
#[derive(Clone, Default)]
struct State {
    segments: Arc<Vec<Arc<Segment>>>,
    // a buffer being flushed: still searched until its segment is in the manifest
    frozen: Option<Arc<Buffer>>,
}

pub struct Segments {
    // None in memory: the buffer holds everything and is never flushed
    dir: Option<PathBuf>,
    // lock order: buffer, then state, then dead
    buffer: RwLock<Buffer>,
    state: RwLock<State>,
    dead: RwLock<HashSet<u64>>,
    // dead ids whose segments must be rewritten now (#249)
    erase: Mutex<HashSet<u64>>,
    next_gen: AtomicU64,
    flushed_through: AtomicU64,
    // replaced segments, erased once no search holds them
    retired: Mutex<Vec<Arc<Segment>>>,
    // one maintain() (or bulk_load) at a time
    maintenance: Mutex<()>,
    woken: Mutex<bool>,
    wake: Condvar,
    flush_postings: usize,
    flush_age: Duration,
}

/// Overwrites a file with zeros, syncs it, then removes it: unlinking alone leaves the text in
/// the freed blocks
pub fn erase_file(path: &Path) -> io::Result<()> {
    let len = fs::metadata(path)?.len();
    let mut file = OpenOptions::new().write(true).open(path)?;
    let zeros = vec![0u8; 1 << 20];
    let mut left = len;
    while left > 0 {
        let n = left.min(zeros.len() as u64) as usize;
        file.write_all(&zeros[..n])?;
        left -= n as u64;
    }
    file.sync_all()?;
    drop(file);
    fs::remove_file(path)
}

// (next_gen, flushed_through, segment file names); None if there's no manifest yet
fn read_manifest(dir: &Path) -> io::Result<Option<(u64, u64, Vec<String>)>> {
    let text = match fs::read_to_string(dir.join("MANIFEST")) {
        Ok(text) => text,
        Err(err) if err.kind() == io::ErrorKind::NotFound => return Ok(None),
        Err(err) => return Err(err),
    };
    let bad = || io::Error::new(io::ErrorKind::InvalidData, "corrupt MANIFEST");
    let mut lines = text.lines();
    if lines.next() != Some("ipxman 1") {
        return Err(bad());
    }
    let mut value = |key: &str, radix: u32| -> io::Result<u64> {
        let line = lines.next().ok_or_else(bad)?;
        let rest = line.strip_prefix(key).ok_or_else(bad)?;
        u64::from_str_radix(rest.trim(), radix).map_err(|_| bad())
    };
    let next_gen = value("next_gen", 16)?;
    let flushed_through = value("flushed_through", 10)?;
    let names = lines
        .map(|line| line.split(' ').next().unwrap_or("").to_string())
        .collect();
    Ok(Some((next_gen, flushed_through, names)))
}

fn write_manifest(
    dir: &Path,
    next_gen: u64,
    flushed_through: u64,
    segments: &[Arc<Segment>],
) -> io::Result<()> {
    let mut text = format!(
        "ipxman 1\nnext_gen {:x}\nflushed_through {}\n",
        next_gen, flushed_through
    );
    for segment in segments {
        let info = segment.info();
        let name = segment.path().file_name().unwrap().to_string_lossy();
        text += &format!(
            "{} {} {} {} {}\n",
            name, info.min_id, info.max_id, info.docs, info.bytes
        );
    }
    let tmp = dir.join("MANIFEST.tmp");
    let mut file = File::create(&tmp)?;
    file.write_all(text.as_bytes())?;
    file.sync_all()?;
    fs::rename(&tmp, dir.join("MANIFEST"))?;
    File::open(dir)?.sync_all()
}

impl Segments {
    fn new(dir: Option<PathBuf>) -> Segments {
        Segments {
            dir,
            buffer: RwLock::new(Buffer::default()),
            state: RwLock::new(State::default()),
            dead: RwLock::new(HashSet::new()),
            erase: Mutex::new(HashSet::new()),
            next_gen: AtomicU64::new(1),
            flushed_through: AtomicU64::new(0),
            retired: Mutex::new(Vec::new()),
            maintenance: Mutex::new(()),
            woken: Mutex::new(false),
            wake: Condvar::new(),
            flush_postings: FLUSH_POSTINGS,
            flush_age: FLUSH_AGE,
        }
    }

    /// Opens (or creates) the segments in `dir`; files the manifest doesn't name, left by a crash
    /// mid-write, are erased
    pub fn open(dir: &Path) -> io::Result<Segments> {
        fs::create_dir_all(dir)?;
        let (next_gen, flushed_through, names) = read_manifest(dir)?.unwrap_or((1, 0, Vec::new()));
        let mut live = Vec::new();
        for name in &names {
            live.push(Arc::new(Segment::open(&dir.join(name))?));
        }
        for entry in fs::read_dir(dir)? {
            let name = entry?.file_name().to_string_lossy().into_owned();
            if name == "MANIFEST.tmp" || (name.ends_with(".seg") && !names.contains(&name)) {
                erase_file(&dir.join(&name))?;
            }
        }
        let segments = Segments::new(Some(dir.to_path_buf()));
        segments.next_gen.store(next_gen, Ordering::SeqCst);
        segments
            .flushed_through
            .store(flushed_through, Ordering::SeqCst);
        segments.state.write().unwrap().segments = Arc::new(live);
        Ok(segments)
    }

    pub fn in_memory() -> Segments {
        Segments::new(None)
    }

    /// The highest page id whose postings are in a segment file
    pub fn flushed_through(&self) -> u64 {
        self.flushed_through.load(Ordering::SeqCst)
    }

    /// Adds a page's postings to the write buffer; ids must ascend across calls
    pub fn add(&self, id: u64, length: u32, keywords: &HashMap<String, u32>) {
        let mut buffer = self.buffer.write().unwrap();
        for (term, &count) in keywords {
            buffer
                .postings
                .entry(term.clone())
                .or_default()
                .push((id, count));
        }
        buffer.lengths.insert(id, length);
        buffer.count += keywords.len();
        buffer.max_id = buffer.max_id.max(id);
        buffer.since.get_or_insert_with(Instant::now);
        let full = buffer.count >= self.flush_postings;
        drop(buffer);
        if full {
            self.wake();
        }
    }

    /// The live pages a term is on, as (id, count, page length)
    pub fn postings(&self, term: &str) -> io::Result<Vec<(u64, u32, u32)>> {
        let in_buffer = |buffer: &Buffer| -> Vec<(u64, u32, u32)> {
            buffer.postings.get(term).map_or(Vec::new(), |list| {
                list.iter()
                    .map(|&(id, count)| (id, count, buffer.lengths[&id]))
                    .collect()
            })
        };
        // the buffer and state together, so a flush moving postings between them isn't missed
        let (state, mut found) = {
            let buffer = self.buffer.read().unwrap();
            let state = self.state.read().unwrap().clone();
            (state, in_buffer(&buffer))
        };
        if let Some(frozen) = &state.frozen {
            found.extend(in_buffer(frozen));
        }
        for segment in state.segments.iter() {
            for (id, count) in segment.postings(term.as_bytes())? {
                found.push((id, count, segment.length(id).unwrap_or(0)));
            }
        }
        let dead = self.dead.read().unwrap();
        found.retain(|(id, _, _)| !dead.contains(id));
        Ok(found)
    }

    /// Pages search must no longer return: hidden at once, and dropped from the buffer
    pub fn set_dead(&self, ids: &[u64]) {
        if ids.is_empty() {
            return;
        }
        self.dead.write().unwrap().extend(ids);
        let mut buffer = self.buffer.write().unwrap();
        let gone: HashSet<u64> = ids
            .iter()
            .copied()
            .filter(|id| buffer.lengths.remove(id).is_some())
            .collect();
        if gone.is_empty() {
            return;
        }
        let mut removed = 0;
        buffer.postings.retain(|_, list| {
            let before = list.len();
            list.retain(|(id, _)| !gone.contains(id));
            removed += before - list.len();
            !list.is_empty()
        });
        buffer.count -= removed;
    }

    /// Dead pages whose segment files must be rewritten without them promptly (#249)
    pub fn mark_erase(&self, ids: &[u64]) {
        if ids.is_empty() {
            return;
        }
        self.erase.lock().unwrap().extend(ids);
        self.wake();
    }

    fn wake(&self) {
        *self.woken.lock().unwrap() = true;
        self.wake.notify_one();
    }

    /// Blocks until there's work (a full buffer, an erase) or a timeout; for the upkeep thread
    pub fn wait(&self) {
        // retired files are polled for until no search holds them
        let timeout = if self.retired.lock().unwrap().is_empty() {
            Duration::from_secs(1)
        } else {
            Duration::from_millis(100)
        };
        let woken = self.woken.lock().unwrap();
        let (mut woken, _) = self
            .wake
            .wait_timeout_while(woken, timeout, |woken| !*woken)
            .unwrap();
        *woken = false;
    }

    /// Writes the buffer to a segment now (a clean shutdown, tests)
    pub fn flush(&self) -> io::Result<()> {
        let _maintenance = self.maintenance.lock().unwrap();
        self.flush_locked()
    }

    /**
     * One round of upkeep: flush the buffer if it's full or old. Returns the dead ids that no
     * segment (or buffer) holds any more, whose records the caller can drop.
     */
    pub fn maintain(&self) -> io::Result<Vec<u64>> {
        let _maintenance = self.maintenance.lock().unwrap();
        if self.flush_due() {
            self.flush_locked()?;
        }
        Ok(self.prune_dead())
    }

    fn flush_due(&self) -> bool {
        if self.state.read().unwrap().frozen.is_some() {
            return true; // a failed flush, retried
        }
        let buffer = self.buffer.read().unwrap();
        buffer.count >= self.flush_postings
            || buffer
                .since
                .is_some_and(|since| since.elapsed() >= self.flush_age)
    }

    fn flush_locked(&self) -> io::Result<()> {
        if self.dir.is_none() {
            return Ok(());
        }
        let frozen = {
            let mut buffer = self.buffer.write().unwrap();
            let mut state = self.state.write().unwrap();
            match &state.frozen {
                Some(frozen) => frozen.clone(),
                None => {
                    if buffer.since.is_none() {
                        return Ok(());
                    }
                    let taken = Arc::new(std::mem::take(&mut *buffer));
                    state.frozen = Some(taken.clone());
                    taken
                }
            }
        };
        let dead = self.dead.read().unwrap().clone();
        let segment = self.write_segment(|writer| {
            for (&id, &length) in &frozen.lengths {
                if !dead.contains(&id) {
                    writer.add_doc(id, length)?;
                }
            }
            for (term, list) in &frozen.postings {
                let live: Vec<Posting> = list
                    .iter()
                    .copied()
                    .filter(|(id, _)| !dead.contains(id))
                    .collect();
                if !live.is_empty() {
                    writer.add_term(term.as_bytes(), &live)?;
                }
            }
            Ok(())
        })?;
        let mut live: Vec<Arc<Segment>> = self.state.read().unwrap().segments.to_vec();
        live.extend(segment);
        let flushed_through = self.flushed_through().max(frozen.max_id);
        self.install(live, flushed_through, true)
    }

    // writes a new segment file; a failed write's partial file is erased. None if it has no pages.
    fn write_segment(
        &self,
        fill: impl FnOnce(&mut SegmentWriter) -> io::Result<()>,
    ) -> io::Result<Option<Arc<Segment>>> {
        let dir = self.dir.as_ref().expect("segment files need a directory");
        let generation = self.next_gen.fetch_add(1, Ordering::SeqCst);
        let path = dir.join(format!("{:016x}.seg", generation));
        let written = SegmentWriter::create(&path).and_then(|mut writer| {
            fill(&mut writer)?;
            writer.finish()
        });
        match written {
            Ok(info) if info.docs == 0 => {
                erase_file(&path)?;
                Ok(None)
            }
            Ok(_) => Ok(Some(Arc::new(Segment::open(&path)?))),
            Err(err) => {
                if path.exists() {
                    let _ = erase_file(&path);
                }
                Err(err)
            }
        }
    }

    // makes `live` the segment list: the manifest first, then what searches see
    fn install(
        &self,
        mut live: Vec<Arc<Segment>>,
        flushed_through: u64,
        clear_frozen: bool,
    ) -> io::Result<()> {
        live.sort_by_key(|segment| segment.info().min_id);
        let dir = self.dir.as_ref().expect("segment files need a directory");
        write_manifest(
            dir,
            self.next_gen.load(Ordering::SeqCst),
            flushed_through,
            &live,
        )?;
        self.flushed_through
            .store(flushed_through, Ordering::SeqCst);
        let mut state = self.state.write().unwrap();
        state.segments = Arc::new(live);
        if clear_frozen {
            state.frozen = None;
        }
        Ok(())
    }

    // drops dead ids that nothing holds any more, and returns them
    fn prune_dead(&self) -> Vec<u64> {
        let buffer = self.buffer.read().unwrap();
        let state = self.state.read().unwrap().clone();
        let mut dead = self.dead.write().unwrap();
        let gone: Vec<u64> = dead
            .iter()
            .copied()
            .filter(|&id| {
                !buffer.lengths.contains_key(&id)
                    && !state
                        .frozen
                        .as_ref()
                        .is_some_and(|f| f.lengths.contains_key(&id))
                    && !state.segments.iter().any(|s| s.contains(id))
            })
            .collect();
        for id in &gone {
            dead.remove(id);
        }
        gone
    }

    /// Replaces every segment with one written by `fill`, for the #247 migration. What was
    /// there (from an interrupted earlier attempt) is erased.
    pub fn bulk_load(
        &self,
        flushed_through: u64,
        fill: impl FnOnce(&mut SegmentWriter) -> io::Result<()>,
    ) -> io::Result<()> {
        let _maintenance = self.maintenance.lock().unwrap();
        let old: Vec<Arc<Segment>> = self.state.read().unwrap().segments.to_vec();
        let segment = self.write_segment(fill)?;
        self.install(segment.into_iter().collect(), flushed_through, false)?;
        for segment in old {
            let path = segment.path().to_path_buf();
            drop(segment);
            erase_file(&path)?;
        }
        Ok(())
    }
}
```

```rust
    // rewrites every segment holding a page marked for erasure
    fn erase_pending(&self) -> io::Result<()> {
        let targets: Vec<u64> = self.erase.lock().unwrap().iter().copied().collect();
        if targets.is_empty() {
            return Ok(());
        }
        let live = self.state.read().unwrap().segments.clone();
        for segment in live.iter() {
            if targets.iter().any(|&id| segment.contains(id)) {
                self.rewrite(std::slice::from_ref(segment))?;
            }
        }
        // done with ids no live segment holds; one marked meanwhile waits for the next round
        let live = self.state.read().unwrap().segments.clone();
        self.erase
            .lock()
            .unwrap()
            .retain(|&id| live.iter().any(|s| s.contains(id)));
        Ok(())
    }

    // a mostly-dead segment on its own, else TIER_FANOUT segments of one size tier
    fn pick_merge(&self) -> Option<Vec<Arc<Segment>>> {
        let live = self.state.read().unwrap().segments.clone();
        let dead = self.dead.read().unwrap();
        for segment in live.iter() {
            let n = dead.iter().filter(|&&id| segment.contains(id)).count() as u64;
            if n > 0 && n * 100 >= segment.info().docs * DEAD_PERCENT {
                return Some(vec![segment.clone()]);
            }
        }
        let mut tiers: BTreeMap<u32, Vec<Arc<Segment>>> = BTreeMap::new();
        for segment in live.iter() {
            let tier = (segment.info().bytes >> 20).max(1).ilog10();
            tiers.entry(tier).or_default().push(segment.clone());
        }
        tiers.into_values().find_map(|mut tier| {
            (tier.len() >= TIER_FANOUT).then(|| {
                tier.truncate(TIER_FANOUT);
                tier
            })
        })
    }

    // replaces `inputs` with one segment of their live pages; the inputs are retired
    fn rewrite(&self, inputs: &[Arc<Segment>]) -> io::Result<()> {
        let dead = self.dead.read().unwrap().clone();
        let merged = self.write_segment(|writer| {
            // page ids never repeat across segments, but their ranges can interleave
            let mut docs: Vec<_> = inputs.iter().map(|s| s.docs().peekable()).collect();
            loop {
                let next = docs
                    .iter_mut()
                    .enumerate()
                    .filter_map(|(i, d)| d.peek().map(|&(id, _)| (id, i)))
                    .min();
                let Some((_, i)) = next else { break };
                let (id, length) = docs[i].next().unwrap();
                if !dead.contains(&id) {
                    writer.add_doc(id, length)?;
                }
            }
            let mut terms = inputs
                .iter()
                .map(|s| s.terms())
                .collect::<io::Result<Vec<_>>>()?;
            let mut heads = terms
                .iter_mut()
                .map(|t| t.next().transpose())
                .collect::<io::Result<Vec<_>>>()?;
            while let Some(term) = heads.iter().flatten().map(|h| h.0.clone()).min() {
                let mut list = Vec::new();
                for i in 0..heads.len() {
                    if heads[i].as_ref().is_some_and(|h| h.0 == term) {
                        let (_, df, offset) = heads[i].take().unwrap();
                        let postings = inputs[i].postings_at(df, offset)?;
                        list.extend(postings.into_iter().filter(|(id, _)| !dead.contains(id)));
                        heads[i] = terms[i].next().transpose()?;
                    }
                }
                if !list.is_empty() {
                    list.sort_unstable();
                    writer.add_term(&term, &list)?;
                }
            }
            Ok(())
        })?;
        let mut live: Vec<Arc<Segment>> = self
            .state
            .read()
            .unwrap()
            .segments
            .iter()
            .filter(|s| !inputs.iter().any(|input| Arc::ptr_eq(s, input)))
            .cloned()
            .collect();
        live.extend(merged);
        self.install(live, self.flushed_through(), false)?;
        self.retired.lock().unwrap().extend(inputs.iter().cloned());
        Ok(())
    }

    // erases retired files no search holds any more (only `retired` has them)
    fn retire(&self) -> io::Result<()> {
        let mut retired = self.retired.lock().unwrap();
        let (ready, held): (Vec<_>, Vec<_>) = retired
            .drain(..)
            .partition(|segment| Arc::strong_count(segment) == 1);
        *retired = held;
        drop(retired);
        for segment in ready {
            let path = segment.path().to_path_buf();
            drop(segment);
            // on failure the file stays unnamed by the manifest, so the next open erases it
            erase_file(&path)?;
        }
        Ok(())
    }

    /**
     * Distinct terms, and the n on the most pages (df descending, then term), over the segments
     * and the buffer. Like Lucene's docFreq this counts dead pages not merged away yet, so it's
     * for /status and /keywords, not ranking. On disk it's cached (see STATS_TTL).
     */
    pub fn term_stats(&self, n: usize) -> io::Result<(usize, Vec<(String, u32)>)> {
        if self.dir.is_none() || n > STATS_TOP {
            return self.compute_term_stats(n);
        }
        let mut cache = self.stats.lock().unwrap();
        if let Some((at, count, top)) = &*cache {
            if at.elapsed() < STATS_TTL {
                return Ok((*count, top.iter().take(n).cloned().collect()));
            }
        }
        let (count, top) = self.compute_term_stats(STATS_TOP)?;
        *cache = Some((Instant::now(), count, top.clone()));
        Ok((count, top.into_iter().take(n).collect()))
    }

    fn compute_term_stats(&self, n: usize) -> io::Result<(usize, Vec<(String, u32)>)> {
        type Source = Box<dyn Iterator<Item = io::Result<(Vec<u8>, u64)>>>;
        let in_buffer = |buffer: &Buffer| -> Source {
            let terms: Vec<_> = buffer
                .postings
                .iter()
                .map(|(t, list)| Ok((t.as_bytes().to_vec(), list.len() as u64)))
                .collect();
            Box::new(terms.into_iter())
        };
        let (state, mut sources) = {
            let buffer = self.buffer.read().unwrap();
            let state = self.state.read().unwrap().clone();
            (state, vec![in_buffer(&buffer)])
        };
        if let Some(frozen) = &state.frozen {
            sources.push(in_buffer(frozen));
        }
        for segment in state.segments.iter() {
            let terms = segment.terms()?.map(|t| t.map(|(term, df, _)| (term, df)));
            sources.push(Box::new(terms));
        }
        let mut heads = sources
            .iter_mut()
            .map(|s| s.next().transpose())
            .collect::<io::Result<Vec<_>>>()?;
        let mut count = 0;
        // the best n so far, smallest first: (df, then the earlier term ranks higher)
        let mut top: BinaryHeap<Reverse<(u64, Reverse<Vec<u8>>)>> = BinaryHeap::new();
        while let Some(term) = heads.iter().flatten().map(|h| h.0.clone()).min() {
            let mut df = 0;
            for i in 0..heads.len() {
                if heads[i].as_ref().is_some_and(|h| h.0 == term) {
                    df += heads[i].take().unwrap().1;
                    heads[i] = sources[i].next().transpose()?;
                }
            }
            count += 1;
            if n > 0 {
                top.push(Reverse((df, Reverse(term))));
                if top.len() > n {
                    top.pop();
                }
            }
        }
        let mut ranked: Vec<(String, u32)> = top
            .into_iter()
            .map(|Reverse((df, Reverse(term)))| {
                (String::from_utf8_lossy(&term).into_owned(), df as u32)
            })
            .collect();
        ranked.sort_by(|a, b| b.1.cmp(&a.1).then_with(|| a.0.cmp(&b.0)));
        Ok((count, ranked))
    }
```

```rust
/**
 * Pages whose postings were still in the write buffer when the process stopped (ids past the
 * last flush) aren't searchable: their rows go, and they're queued to be crawled again.
 */
fn recover_unflushed(conn: &mut Connection, flushed_through: u64) -> rusqlite::Result<()> {
    let tx = conn.transaction()?;
    let items: Vec<String> = tx
        .prepare("SELECT item FROM pages WHERE id > ?1 ORDER BY id")?
        .query_map([flushed_through as i64], |r| r.get(0))?
        .collect::<rusqlite::Result<_>>()?;
    if items.is_empty() {
        return Ok(());
    }
    log::warn!(
        "{} pages weren't flushed to a segment before the last stop; queueing them again",
        items.len()
    );
    tx.execute(
        "DELETE FROM mirrors WHERE page IN (SELECT id FROM pages WHERE id > ?1)",
        [flushed_through as i64],
    )?;
    tx.execute("DELETE FROM pages WHERE id > ?1", [flushed_through as i64])?;
    {
        let mut queue = tx.prepare("INSERT OR IGNORE INTO queue (item) VALUES (?1)")?;
        for item in &items {
            queue.execute([item])?;
        }
    }
    tx.commit()
}

/**
 * #247: postings move from SQLite into segment files. Streams the postings table (in term order
 * already) into one segment, then drops it, rebuilds `pages` with AUTOINCREMENT keeping its ids,
 * and vacuums. If this is interrupted the postings table is still there, and the next start
 * redoes it, erasing the segment the earlier attempt wrote.
 */
fn migrate_postings_to_segments(
    conn: &mut Connection,
    segments: &Segments,
) -> Result<(), OpenError> {
    let has_postings: bool = conn
        .prepare("SELECT 1 FROM sqlite_master WHERE type = 'table' AND name = 'postings'")?
        .exists([])?;
    if !has_postings {
        return Ok(());
    }
    info!("Moving postings into segment files (one-time, #247)");
    let max_id: i64 = conn.query_row("SELECT coalesce(max(id), 0) FROM pages", [], |r| r.get(0))?;
    let sql = std::io::Error::other;
    segments.bulk_load(max_id as u64, |writer| {
        let mut docs = conn
            .prepare("SELECT id, length FROM pages ORDER BY id")
            .map_err(sql)?;
        let mut rows = docs.query([]).map_err(sql)?;
        while let Some(row) = rows.next().map_err(sql)? {
            let id: i64 = row.get(0).map_err(sql)?;
            let length: i64 = row.get(1).map_err(sql)?;
            writer.add_doc(id as u64, length as u32)?;
        }
        // BINARY collation is bytewise, the order segments need
        let mut postings = conn
            .prepare(
                "SELECT postings.term, postings.page, postings.count FROM postings
                 JOIN pages ON pages.id = postings.page ORDER BY postings.term, postings.page",
            )
            .map_err(sql)?;
        let mut rows = postings.query([]).map_err(sql)?;
        let (mut term, mut list): (Option<String>, Vec<Posting>) = (None, Vec::new());
        while let Some(row) = rows.next().map_err(sql)? {
            let next: String = row.get(0).map_err(sql)?;
            if term.as_deref() != Some(next.as_str()) {
                if let Some(done) = term.replace(next) {
                    writer.add_term(done.as_bytes(), &list)?;
                    list.clear();
                }
            }
            let page: i64 = row.get(1).map_err(sql)?;
            let count: i64 = row.get(2).map_err(sql)?;
            list.push((page as u64, count as u32));
        }
        if let Some(done) = term {
            writer.add_term(done.as_bytes(), &list)?;
        }
        Ok(())
    })?;
    let tx = conn.transaction()?;
    tx.execute_batch(
        "CREATE TABLE pages_new (
             id         INTEGER PRIMARY KEY AUTOINCREMENT,
             item       TEXT NOT NULL UNIQUE,
             cid        TEXT NOT NULL,
             title      TEXT NOT NULL,
             excerpt    TEXT NOT NULL,
             indexed_at INTEGER NOT NULL,
             length     INTEGER NOT NULL DEFAULT 0,
             text_hash  BLOB
         );
         INSERT INTO pages_new (id, item, cid, title, excerpt, indexed_at, length, text_hash)
           SELECT id, item, cid, title, excerpt, indexed_at, length, text_hash FROM pages;
         DROP TABLE pages;
         ALTER TABLE pages_new RENAME TO pages;
         DROP TABLE postings;
         DROP TABLE terms;",
    )?;
    tx.commit()?;
    // secure_delete zeroed the dropped tables' pages; this gives the space back
    conn.execute_batch("VACUUM")?;
    Ok(())
}
```

```rust
    /**
     * Adds or replaces a page: its row here, its postings (from result.keywords) in the segment
     * write buffer. A re-crawl gets a new id; the old one goes to `dead_pages`. If another item
     * already has the same text (result.text_hash), the page isn't indexed: it's recorded as a
     * mirror of that one instead.
     */
    pub fn upsert(
        &self,
        item: &str,
        result: &IndexResult,
        indexed_at: i64,
    ) -> rusqlite::Result<Upserted> {
        // timed (with queue_add and queue_pop) to tell lock contention from slow disk: waited is
        // for the connection lock, took is the transaction itself
        let start = Instant::now();
        let mut conn = self.conn.lock().unwrap();
        let waited = start.elapsed();
        let tx = conn.transaction()?;
        if let Some(hash) = &result.text_hash {
            let original: Option<(i64, String)> = tx
                .prepare_cached("SELECT id, item FROM pages WHERE text_hash = ?1 AND item != ?2")?
                .query_row(params![hash, item], |r| Ok((r.get(0)?, r.get(1)?)))
                .optional()?;
            if let Some((page, original)) = original {
                // indexed under this item before its text matched: drop it, and point its own
                // mirrors at the original instead
                let removed = self.remove_page(&tx, item)?;
                if let Some((old, _)) = removed {
                    tx.prepare_cached("UPDATE mirrors SET page = ?2 WHERE page = ?1")?
                        .execute(params![old, page])?;
                }
                tx.prepare_cached(
                    "INSERT INTO mirrors (item, page) VALUES (?1, ?2)
                     ON CONFLICT (item) DO UPDATE SET page = excluded.page",
                )?
                .execute(params![item, page])?;
                tx.commit()?;
                drop(conn);
                if let Some((old, length)) = removed {
                    self.segments.set_dead(&[old as u64]);
                    self.adjust_lengths(1, length);
                }
                info!(
                    "Store upsert {}: mirror of {}, waited {:?}, took {:?}",
                    item,
                    original,
                    waited,
                    start.elapsed() - waited
                );
                return Ok(Upserted::Mirror(original));
            }
        }
        tx.prepare_cached("DELETE FROM mirrors WHERE item = ?1")?
            .execute([item])?;
        let length: i64 = result.keywords.values().map(|&count| count as i64).sum();
        // a re-crawl gets a new id: the old version's postings are in a segment, which can't change
        let old = self.remove_page(&tx, item)?;
        let id: i64 = tx.query_row(
            "INSERT INTO pages (item, cid, title, excerpt, indexed_at, length, text_hash)
             VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7) RETURNING id",
            params![
                item,
                result.cid,
                result.title,
                result.excerpt,
                indexed_at,
                length,
                result.text_hash
            ],
            |r| r.get(0),
        )?;
        if let Some((old, _)) = old {
            tx.prepare_cached("UPDATE mirrors SET page = ?2 WHERE page = ?1")?
                .execute(params![old, id])?;
        }
        tx.commit()?;
        // still under the connection lock, so ids reach the buffer in ascending order
        self.segments.add(id as u64, length as u32, &result.keywords);
        drop(conn);
        if let Some((old, old_length)) = old {
            self.segments.set_dead(&[old as u64]);
            self.adjust_lengths(1, old_length);
        }
        self.pages.fetch_add(1, Ordering::Relaxed);
        self.lengths.fetch_add(length as u64, Ordering::Relaxed);
        info!(
            "Store upsert {}: {} terms, waited {:?}, took {:?}",
            item,
            result.keywords.len(),
            waited,
            start.elapsed() - waited
        );
        Ok(Upserted::Indexed)
    }

    // deletes an item's page, recording its id in dead_pages; returns the id and its length
    fn remove_page(&self, tx: &Transaction, item: &str) -> rusqlite::Result<Option<(i64, u64)>> {
        let row: Option<(i64, i64, String)> = tx
            .prepare_cached("DELETE FROM pages WHERE item = ?1 RETURNING id, length, cid")?
            .query_row([item], |r| Ok((r.get(0)?, r.get(1)?, r.get(2)?)))
            .optional()?;
        let Some((id, length, cid)) = row else {
            return Ok(None);
        };
        tx.prepare_cached(
            "INSERT INTO dead_pages (id, item, cid, died_at, erase) VALUES (?1, ?2, ?3, ?4, 0)",
        )?
        .execute(params![id, item, cid, now_secs()])?;
        Ok(Some((id, length as u64)))
    }

    /**
     * Deletes pages and their mirrors in one transaction (items that are mirrors themselves are
     * dropped too); returns how many pages went. They leave search at once. With `erase`
     * (takedowns, expiry), the segment files holding them or any earlier version of them are
     * rewritten without them promptly (#249).
     */
    pub fn delete(&self, items: &[String], erase: bool) -> rusqlite::Result<usize> {
        let mut conn = self.conn.lock().unwrap();
        let tx = conn.transaction()?;
        let (mut dead, mut erased, mut length) = (Vec::new(), Vec::new(), 0);
        {
            let mut mirror = tx.prepare("DELETE FROM mirrors WHERE item = ?1")?;
            let mut mirrors_of = tx.prepare("DELETE FROM mirrors WHERE page = ?1")?;
            let mut versions =
                tx.prepare("UPDATE dead_pages SET erase = 1 WHERE item = ?1 RETURNING id")?;
            for item in items {
                mirror.execute([item])?;
                if let Some((id, page_length)) = self.remove_page(&tx, item)? {
                    dead.push(id as u64);
                    length += page_length;
                    mirrors_of.execute([id])?;
                }
                if erase {
                    // this page and every superseded version of it
                    for id in versions.query_map([item], |r| r.get::<_, i64>(0))? {
                        erased.push(id? as u64);
                    }
                }
            }
        }
        tx.commit()?;
        drop(conn);
        self.segments.set_dead(&dead);
        self.segments.mark_erase(&erased);
        self.adjust_lengths(dead.len(), length);
        Ok(dead.len())
    }

    /// Every dead page version still recorded, as (id, item, cid, when it died)
    pub fn dead_versions(&self) -> rusqlite::Result<Vec<(u64, String, String, i64)>> {
        let conn = self.conn.lock().unwrap();
        let mut stmt = conn.prepare("SELECT id, item, cid, died_at FROM dead_pages")?;
        let rows = stmt.query_map([], |r| {
            Ok((r.get::<_, i64>(0)? as u64, r.get(1)?, r.get(2)?, r.get(3)?))
        })?;
        rows.collect()
    }

    /// Dead versions to erase from the segment files promptly (#249)
    pub fn erase_ids(&self, ids: &[u64]) -> rusqlite::Result<()> {
        let mut conn = self.conn.lock().unwrap();
        let tx = conn.transaction()?;
        {
            let mut stmt = tx.prepare("UPDATE dead_pages SET erase = 1 WHERE id = ?1")?;
            for &id in ids {
                stmt.execute([id as i64])?;
            }
        }
        tx.commit()?;
        drop(conn);
        self.segments.mark_erase(ids);
        Ok(())
    }
```

```rust
    pub fn top_terms(&self, n: usize) -> std::io::Result<Vec<(String, u32)>> {

    /// One round of segment upkeep (see Segments::maintain); drops dead_pages rows no segment
    /// needs any more
    pub fn maintain(&self) {
        let dropped = match self.segments.maintain() {
            Ok(dropped) => dropped,
            Err(err) => {
                log::warn!("Segment upkeep failed: {}", err);
                return;
            }
        };
        if dropped.is_empty() {
            return;
        }
        let mut conn = self.conn.lock().unwrap();
        let deleted = conn.transaction().and_then(|tx| {
            {
                let mut stmt = tx.prepare_cached("DELETE FROM dead_pages WHERE id = ?1")?;
                for &id in &dropped {
                    stmt.execute([id as i64])?;
                }
            }
            tx.commit()
        });
        if let Err(err) = deleted {
            log::warn!("Couldn't drop {} dead page ids: {}", dropped.len(), err);
        }
    }

    /// Blocks until there's segment upkeep to do, or a second passes
    pub fn wait_for_maintenance(&self) {
        self.segments.wait();
    }

    /// Writes buffered postings to a segment now
    pub fn flush(&self) -> std::io::Result<()> {
        self.segments.flush()
```

```rust
        let groups = parse_query(query);
        let pages = self.map.len() as f64;
        let average = self.store().average_length().max(1.0);
        // each distinct term's postings, read once: page id -> (count, page length)
        let mut postings: HashMap<&str, HashMap<u64, (u32, u32)>> = HashMap::new();
        for group in &groups {
            for term in group {
                if postings.contains_key(term.as_str()) {
                    continue;
                }
                match self.store().postings(term) {
                    Ok(found) => postings.insert(
                        term,
                        found
                            .into_iter()
                            .map(|(page, count, length)| (page, (count, length)))
                            .collect(),
                    ),
                    Err(err) => {
                        warn!("Couldn't search for {:?}: {}", term, err);
                        return (0, Vec::new());
                    }
                };
            }
            // a group none of whose terms are indexed matches nothing; skip reading the rest
            if group.iter().all(|term| postings[term.as_str()].is_empty()) {
                return (0, Vec::new());
            }
        }
        let weight = |term: &str, (count, length): (u32, u32)| {
            let df = postings[term].len() as f64;
            let idf = (1.0 + (pages - df + 0.5) / (df + 0.5)).ln();
            let count = count as f64;
            let norm = BM25_K1 * (1.0 - BM25_B + BM25_B * length as f64 / average);
            idf * count * (BM25_K1 + 1.0) / (count + norm)
        };
        let has = |group: &Vec<String>, page: &u64| {
            group
                .iter()
                .any(|term| postings[term.as_str()].contains_key(page))
        };
        // candidates from the group with the fewest postings, kept if they match every group
        let size = |group: &&Vec<String>| -> usize {
            group.iter().map(|term| postings[term.as_str()].len()).sum()
        };
        let mut matches: HashSet<u64> = match groups.iter().min_by_key(size) {
            Some(smallest) => smallest
                .iter()
                .flat_map(|term| postings[term.as_str()].keys().copied())
                .collect(),
            None => HashSet::new(),
        };
        matches.retain(|page| groups.iter().all(|group| has(group, page)));
        let mut ranked: Vec<(f64, u64)> = matches
            .into_iter()
            .map(|page| {
                let score: f64 = postings
                    .iter()
                    .filter_map(|(term, found)| found.get(&page).map(|p| weight(term, *p)))
                    .sum();
                (score, page)
            })
            .collect();
        // ties: the page indexed first
        ranked.sort_by(|a, b| b.0.total_cmp(&a.0).then(a.1.cmp(&b.1)));
        let total = ranked.len();
        // resolve only the requested page of results to items, not every match
        let shown: Vec<u64> = ranked
            .into_iter()
            .skip(offset)
            .take(limit)
            .map(|(_, page)| page)
            .collect();

            Err(err) => {

                return (0, Vec::new());
            }

        let results = shown
            .iter()
            .filter_map(|page| items.get(page))
            .filter_map(|item| self.map.get(item).map(|r| r.clone()));
        (total, results.collect())
    }
```
